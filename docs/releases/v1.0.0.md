# Stickey Notes v1.0.0 for macOS

The first macOS release of Stickey Notes: a local home for notes, checklists, drawings, and floating desktop notes.

**Draft status:** The universal v1.0.0 archive is built and remains local. Developer ID distribution signing and Apple notarization are pending. Download assets will be attached after those steps pass; this release has not been published.

## Download and install

- Requires macOS 14 Sonoma or later.
- `Stickey-Notes-v1.0.0-macOS-universal.zip` supports both Apple Silicon and Intel Macs.
- Extract the ZIP, move **Stickey Notes.app** to **Applications**, and open it.
- `SHA256SUMS.txt` contains the download's SHA-256 checksum.

## Included

- Notes and checklists with autosave, search, groups, pins, and grid/list views.
- Rich text, 25 note colors, and drawing tools with PNG export.
- Floating desktop notes with saved positions and sizes.
- Version history, restore, duplication, recoverable deletion, and JSON backup/import.
- QR code generation and image scanning.
- Encrypted notes unlocked through Apple's system Touch ID or Mac login password prompt.
- Automatic locking after two minutes, adjustable from 30 seconds to 15 minutes.

## Notes

This Mac release stores notes locally. iCloud sync and WidgetKit widgets are not included in this download.

Apple-locked notes require the Keychain credential on the Mac where they were locked. Their credentials are not included in exported backups and cannot be recovered if lost. Existing note PIN/password locks remain supported.
